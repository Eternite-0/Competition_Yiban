# 2026 易班 AI 功能演示脚本

## 演示前置条件

- 后端、前端和 MySQL 已启动，学生、教师、管理员三个演示账号均可正常登录。
- 环境变量 `AI_API_KEY` 已配置为可调用当前模型服务的有效密钥；未配置时普通业务仍可使用，但证书识别和赛事通知解析不能完成。
- `ai.base-url`、`ai.model` 与 `ai.vision-model` 配置可用，网络能够访问模型服务。
- 七牛云上传配置可用，浏览器能够上传并预览证书文件。
- 准备一张清晰的证书图片，至少包含赛事名称、获奖等级、获奖人、主办方或印章；本脚本不创建图片。
- 使用赛事通知文件：`docs/demo/2026-ai-innovation-competition-notice.txt`。
- 建议提前清理同名演示数据，或在演示时说明系统识别出的重复赛事风险。

## 演示账号分工

| 角色 | 负责操作 |
| --- | --- |
| 学生 | 上传证书、核对 AI 字段、关联成员并提交审核 |
| 教师 | 在成果审核工作台查看证书、证据、置信度和风险，执行审核 |
| 管理员 | 导入赛事通知、复核 AI 草稿并创建未发布赛事 |

## 闭环一：证书识别到成长记录（5 分钟）

### 0:00-0:40 学生进入上传页

1. 使用学生账号登录。
2. 进入“上传获奖凭证”页面。
3. 确认页面显示关联赛事、证书识别、关联成员和提交检查区域。

预期结果：

- 当前学生自动出现在关联成员中。
- 页面允许选择赛事并上传证书图片。
- 未上传证书前，提交按钮保持不可用或提示补全必填项。

### 0:40-1:50 学生上传并识别证书

1. 选择一个已有赛事。
2. 将准备好的证书图片拖入证书识别区域，或点击选择文件。
3. 等待上传和 AI 识别完成。

预期结果：

- 页面显示识别进度，完成后提示“证书识别完成，请核对后提交”。
- AI 回填比赛名称、获奖等级、获奖时间、主办单位、获奖人、证书编号和印章文字。
- 页面显示总置信度、字段置信度、识别证据和风险提示。
- 置信度低于阈值的字段以醒目样式提示重点核对。

### 1:50-2:50 学生核对并提交

1. 对照证书原图修正低置信度或识别错误的字段。
2. 确认赛事名称和获奖等级已填写。
3. 按需搜索并添加团队成员。
4. 点击“提交审核”。

预期结果：

- 系统提示“获奖证明已提交审核”。
- 生成一条待审核获奖证明，并关联所有选中的学生。
- 页面跳转至学生报名或成果记录区域。

### 2:50-4:10 教师审核获奖证明

1. 切换到教师账号。
2. 进入“成果审核工作台”，选择“获奖证明”筛选项。
3. 打开刚提交的记录。
4. 对照证书原图查看学生提交字段、AI 识别字段、文件 Hash、置信度、证据片段和风险提示。
5. 填写审核意见“证书信息与原图一致”，点击“审核通过”。

预期结果：

- 记录从待审核列表移除，并进入已处理记录。
- 页面提示审核通过。
- 审核任务状态被更新，学生收到审核结果消息。

### 4:10-5:00 验证学生侧联动

1. 切换回学生账号。
2. 打开消息中心，查看获奖证明审核通过通知。
3. 打开成长记录或个人成果页面，查找对应赛事与奖项。

预期结果：

- 消息中心出现审核通过通知。
- 成长记录新增一条对应赛事、获奖等级和日期的记录。
- 若证书关联多名学生，每名关联学生均可看到对应成果。

## 闭环二：赛事通知到未发布赛事（3 分钟）

### 0:00-0:35 管理员上传赛事通知

1. 使用管理员账号登录。
2. 进入“AI 导入赛事”页面。
3. 保持“文件”模式，上传 `docs/demo/2026-ai-innovation-competition-notice.txt`。
4. 点击“生成 AI 草稿”。

预期结果：

- 页面依次展示读取来源、识别字段、检测风险和写入草稿的处理状态。
- 解析完成后显示赛事名称、主办单位、赛事级别、报名时间、比赛时间、团队人数和赛道。
- 页面显示字段置信度、证据数量和风险提示。

### 0:35-1:30 管理员复核解析结果

1. 点击“查看并审核”，进入“AI 草稿箱”。
2. 在草稿列表中选择刚生成的待审核草稿。
3. 核对赛事名称、主办单位、报名时间、比赛时间、最大团队人数、标签和赛道。
4. 依次查看“置信度”“证据”“风险”三个质量信息页签。

预期结果：

- 草稿状态为“待审核”。
- 字段值与通知原文一致，证据片段可追溯到原文。
- 若系统中已有同名赛事，风险页签显示疑似重复赛事及相似度；否则显示未发现明显风险。

### 1:30-2:25 管理员修正并确认

1. 如有需要，直接修正字段。
2. 填写审核意见“已核对通知原文，创建赛事草稿”。
3. 点击“确认并进入赛事管理”，在确认框中再次确认。

预期结果：

- 当前修改先被保存。
- AI 草稿状态更新为“已确认”。
- 系统创建一条状态为 `draft` 的未发布赛事，并创建通知中识别到的比赛阶段。
- 页面显示“已创建未发布赛事”，并提供“赛事管理”和“继续编辑”入口。

### 2:25-3:00 验证赛事管理闭环

1. 点击“赛事管理”或“继续编辑”。
2. 查找“2026 年全国大学生人工智能创新应用挑战赛”。
3. 核对赛事仍为未发布状态，且报名时间、比赛时间、团队人数、赛道和阶段信息已写入。

预期结果：

- 新赛事可在现有赛事管理流程中继续补充封面、编辑并发布。
- AI 草稿保留来源、解析任务、审核人和审核意见，便于追溯。

## 异常说明

- 若提示未配置 `AI_API_KEY`，停止 AI 演示并先完成密钥配置；不要将该提示误判为普通业务故障。
- 若证书上传失败，检查七牛云配置、文件格式和网络；证书识别支持 PDF、JPG、PNG、WEBP 等格式。
- 若赛事解析失败，确认上传文件为 UTF-8 文本，并检查模型服务响应。
- 若草稿出现重复风险，保留提示进行讲解，不要直接删除已有赛事数据。
